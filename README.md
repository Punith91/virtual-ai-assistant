 Virtual AI Assistant (Mini Alexa)

A rule-based, offline console assistant built with Python.

## Features
- Greeting and name capture
- Date and time
- Calculator
- Jokes, quotes and facts
- Number guessing game
- Rule-based activity recommendation
- Simple perceptron demo

## How to run
python main.py

## Commands
help, time, date, calculate, joke, quote, fact, game, recommend, perceptron, exit
